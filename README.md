# NTH---SPY
A melhor forma de se proteger contra esse tipo de ameaça é baixar softwares exclusivamente de repositórios oficiais e verificados, manter soluções antivírus/EDR atualizadas e desconfiar de aplicativos que solicitam permissões excessivas (como acesso total ao sistema de arquivos ou à rede) sem justificativa clara para a sua proposta pedagógica.
